# Estructuras
Un array es una lista o caja dividida en casillas numeradas donde guardas varios datos ordenados.
Se crea agrupando esos datos entre corchetes [] separados por comas, o usando un comando del lenguaje que reserva el espacio necesario en memoria para guardarlos.

## Arrays 
Permite almacenar una colección de datos que permite acceder de forma aleatoria

## Métodos
| Método           | Descripción                                                       | Ejemplo            | Parámetro |
| ------           | ----------------------------------------------------------------- | ------------------ | --------- |
| Array.push()     | Añadir un elemento al final                                       | const lista = ["a"]; 
|                                                                                        lista.push("b"); //lista -> ["a","b"]
| Array.splice()   | Añadir o eliminar elementos                                       |
| Array.at()       | Obtener el valor almacenado en una posición                       |
| Array.sort()     | Ordenar el array                                                  |
| Array.find()     | Buscar el elemento que pasa la prueba                             |
| Array.includes() | Comprobar si contiene un elemento                                 |
| Array.filter()   | Obtener un array con todos los elementos que cumplen la condición |
